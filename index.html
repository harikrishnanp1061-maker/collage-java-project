System Architecture, OOP Principles & Viva Prep

How ChronoChef maps directly to the college Java OOP Syllabus (Course PBCST304).

Module 1 & 2

Core OOP & Polymorphism

• Encapsulation: FoodItem.java hides private fields behind validated getters/setters.
• Inheritance: Hierarchical extension by PerishableItem and PackagedItem.
• Dynamic Method Dispatch: Overridden getStorageInstructions() resolved at runtime by the JVM.

Module 1 & 3

Algorithms & PDI Math

• Days Remaining ($D$): Millisecond delta normalized to midnight.
• PDI Formula: $\text{PDI} = \max(1, 100 - (D \times 2))$.
• Bubble Sort: In-memory sorting on Vector<FoodItem> in descending urgency order.

Module 3 & 4

Database & Checked Exceptions

• Singleton Pattern: DatabaseManager.java controls access to chronochef.db.
• DAO Pattern: FoodBankDAO.java implements InventoryOperations.
• Checked Exception: ExpiredItemDistributionException strictly stops expired distribution.

Module 4

Swing GUI & Event Delegation

• CardLayout: Single-window architecture switching across 5 views.
• Event Delegation: ActionListener binds actions to service routines.
• Thread Safety: GUI initialized on the Event Dispatch Thread (EDT).
