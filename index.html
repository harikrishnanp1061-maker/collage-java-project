2. Mathematical Priority Distribution Index (PDI) Formula

Implemented in PriorityPricingService.java:

PDI = 100 - (DaysRemaining * 2)   [Clamped between 1 and 100; 0 for expired]
  • D ≤ 2 Days: 100% Subsidy Tier (Free Emergency Relief clearance)
  • D ≤ 5 Days: 50% Subsidy Tier (Half-Price Community Relief)
  • D > 5 Days: 0% Subsidy (Standard Market Rate)
  • D < 0 Days: Expired / Quarantined — Distribution blocked by ExpiredItemDistributionException

3. Stock Write-Off vs Complete Deletion (Module 4 CRUD)

  • Write-Off Stock (Set to 0): Sets quantity to 0.0 using dao.updateItem(). The item record and SKU remain preserved in the catalog for tracking.
  • Permanently Delete Item Info: Purges the row completely from SQLite using dao.deleteItem(id).
